为什么先从 "分类"和"二分类" 讲起？

机器学习的起点，其实就是回答一个个"是不是 / 属于哪一类"的判断。

?生活里的"是 / 否"
这封邮件是不是垃圾邮件？这个肿瘤是良性还是恶性？这张照片是猫还是狗？这朵鸢尾花是 setosa 还是 versicolor？
✓为什么是"二"分类

✏️
那怎么让机器自己学会这个判断规则？最自然的想法是：画一条分界线把两类点隔开——这就是"线性分类器"，也是感知机的雏形。

00 · 历史线索

感知机 从哪来？

它不是凭空出现的：它受生物神经元启发，是历史上第一个能从数据里"学出"分界线的模型。

1943人工神经元的起点
McCulloch 与 Pitts 提出人工神经元模型——把多个输入加权求和后过一道阈值再输出，是神经网络的源头。
1957感知机诞生
Frank Rosenblatt 提出 Perceptron（感知机），并在 IBM 704 计算机上做了模拟。
1959–60第一台硬件
造出 Mark I Perceptron（"Project PARA"），接上摄像头做图像识别：400 个光电池（20×20）、512 个关联单元、8 个响应单元。
1969第一次"寒冬"
Minsky 与 Papert 在《Perceptrons》中指出：单层感知机连异或 XOR 都学不会，神经网络研究随后陷入低谷。
🧠
一句话理解：感知机就是"加权求和 + 过阈值"的人工神经元， 第一个能自动学出线性分界面的模型，也是今天深度学习的祖先。

01 · 模型

感知机是 二类分类的线性模型

$f(x)=\operatorname{sign}(w\cdot x+b)$
x输入
实例的特征向量，如鸢尾花的 [花萼长, 花萼宽]。
w权重
权重向量，决定超平面的方向（法向量）。
b偏置
偏置（截距），决定超平面离原点多远。
📏
几何意义：方程 $w\cdot x+b=0$ 就是空间中的一条分离超平面（二维时是一条直线）， 它把输入空间切成两半：一侧判 $+1$，另一侧判 $-1$。

前提：数据要线性可分——真能用一条直线把两类点完全分开，否则感知机不适用。

01 · 直觉

符号函数 sign 与 "切一刀"的直觉

sign（符号函数）
$\operatorname{sign}(x)=\begin{cases}+1,& x\ge 0\\ -1,& x<0\end{cases}$
把实数压成两个类别标签 $+1 / -1$。
训练集
$T=\{(x_1,y_1),\dots,(x_N,y_N)\}$
$y_i\in\{+1,-1\}$，学习的目标就是定出 $w$ 和 $b$。
一堆带标签的点
蓝=+1，橙=−1
→
找一条直线
w·x+b=0
→
两边的点分开
新点落在哪边就判哪类
✂️
直觉：感知机就是在平面上切一刀，把两类点分到两侧。直线参数 $(w,b)$ 一变，刀的角度和位置就变。

02 · 承上启下

用第 1 章的 三要素 看感知机

感知机是"模型—策略—算法"框架最小、最完整的样例。

1模型
假设空间 = 所有 $(w,b)$ 决定的分离超平面集合：
$\mathcal F=\{f\mid f(x)=w\cdot x+b\}$
2策略
极小化误分类驱动的损失函数：
$\min\limits_{w,b} L(w,b)=-\!\!\sum\limits_{x_i\in M}\!\!y_i(w\cdot x_i+b)$
3算法
随机梯度下降（SGD），每次挑一个误分类点更新参数。
第 2 章 · 感知机
02 · 策略

损失函数从哪来：误分类点的总距离

第一步：点到超平面的距离
$\dfrac{1}{\lVert w\rVert}\big|w\cdot x_i+b\big|$
对误分类点而言，$w\cdot x_i+b$ 与真实标签 $y_i$ 符号相反，故：
$-y_i(w\cdot x_i+b)>0$
第二步：所有误分类点的总距离
$-\dfrac{1}{\lVert w\rVert}\sum\limits_{x_i\in M}y_i(w\cdot x_i+b)$
忽略常数因子 $\tfrac{1}{\lVert w\rVert}$（不影响最优点），得到感知机的损失函数：
$L(w,b)=-\!\!\sum\limits_{x_i\in M}y_i(w\cdot x_i+b)$
💡
$M$ 是误分类点集合。直觉：分错得越多、分错得越"离谱"（离超平面越远），损失越大； 分对的点不产生损失。所以最小化 $L$ 就是在"把误分类点往正确侧推"。
第 2 章 · 感知机
03 · 算法

学习算法：随机梯度下降

求梯度
对 $L$ 分别关于 $w,b$ 求梯度：
$\nabla_w L=-\!\!\sum\limits_{x_i\in M}y_i x_i,\quad \nabla_b L=-\!\!\sum\limits_{x_i\in M}y_i$
随机选一个误分类点更新
$w\leftarrow w+\eta\,y_i x_i$
$b\leftarrow b+\eta\,y_i$
$\eta$ 为学习率（步长）。
🚀
直观：某个点被误分类（落在错误一侧）时，就用它把超平面朝它那边推一推， 反复迭代，直到所有点都被正确分类。

对应的核心代码（自实现）

if y * self.sign(X, self.w, self.b) <= 0:        # 判定是否误分类: y_i(w·x_i+b) ≤ 0
    self.w = self.w + self.l_rate * np.dot(y, X)   # w ← w + η y_i x_i
    self.b = self.b + self.l_rate * y              # b ← b + η y_i
    wrong_count += 1

03 · 收敛性

Novikoff 定理：什么时候一定会收敛

线性可分 ⇒ 收敛
当训练集线性可分时，感知机算法一定在有限步内收敛，误分类次数 $k$ 有上界：
$k\le\left(\dfrac{R}{\gamma}\right)^{2}$
$R=\max_i\lVert x_i\rVert$（样本最大长度）；$\gamma$ 是能把两类分开的最大间隔。
线性不可分 ⇒ 震荡
若数据不可分，算法不会收敛，$w,b$ 会不停变化（震荡），永远无法做到零误分类。
🎲
重要性质：线性可分时解不唯一——存在无穷多条能分开的直线。 初值不同、迭代顺序不同，最终得到的超平面就可能不同。
第 2 章 · 感知机 · Novikoff 定理（定理 2.1）
04 · 两种形式

原始形式 vs 对偶形式

原始 Primal
直接对 $w,b$ 做梯度下降：
$w\leftarrow w+\eta y_i x_i$
$b\leftarrow b+\eta y_i$
每次更新都直接改动权重与偏置。
对偶 Dual
把 $w,b$ 写成训练样本的线性组合，只更新系数 $\alpha_i$：
$w=\sum\limits_{i=1}^N \alpha_i y_i x_i,\quad b=\sum\limits_{i=1}^N \alpha_i y_i$
更新：$\alpha_i\leftarrow \alpha_i+\eta$。
🔗
对偶形式的好处：训练中只用到样本间的内积 $x_i\cdot x_j$，可以预先算成 Gram 矩阵加速。 这个思想会在第 7 章支持向量机里被进一步发扬（核方法）。

05 · 核心代码

关键模型代码：自实现感知机

class Model:
    def __init__(self):
        self.w = np.ones(len(data[0]) - 1, dtype=np.float32)  # 权重 w，初始化为全 1
        self.b = 0                                            # 偏置 b，初始化为 0
        self.l_rate = 0.1                                     # 学习率 η

    def sign(self, x, w, b):
        return np.dot(x, w) + b   # 计算 w·x + b

    def fit(self, X_train, y_train):        # 随机梯度下降法
        is_wrong = False
        while not is_wrong:                 # 只要还有误分类点就继续迭代
            wrong_count = 0
            for d in range(len(X_train)):   # 遍历每个样本
                X, y = X_train[d], y_train[d]
                if y * self.sign(X, self.w, self.b) <= 0:   # 误分类判定
                    self.w = self.w + self.l_rate * np.dot(y, X)  # w ← w + η y_i x_i
                    self.b = self.b + self.l_rate * y             # b ← b + η y_i
                    wrong_count += 1
            if wrong_count == 0:            # 本轮没有误分类点 → 收敛，退出
                is_wrong = True
        return 'Perceptron Model!'

这段代码就是"策略 + 算法"的直译：循环扫描样本，遇到误分类点就按公式更新 $w,b$，直到一轮内不再有误分类点。

05 · 一个关键的坑

为什么有 1 个点 没分对：tol 参数

⚠️
sklearn 的 Perceptron 有一个 tol 参数：本轮损失与上轮之差小于 tol 时就提前停止， 于是留下了 1 个误分类点。设 tol=None 让它持续迭代，即可做到完全分开。 
clf = Perceptron(fit_intercept=True,
                 max_iter=1000,
                 tol=None,     # ← 关键：关闭提前停止，直到收敛
                 shuffle=True)

06 · 习题 2.1

为什么感知机 表示不了异或 XOR

因为感知机是线性模型，而 XOR 的两个类别是线性不可分的。

$x^{(1)}$$x^{(2)}$$y$
11−1
1−1+1
−11+1
−1−1−1
结论
把 4 个点画在平面上：两个 $+1$ 在对角，两个 $-1$ 在另一条对角。

无论怎么画一条直线，都无法把同号的两点划到同一侧、异号的分开——这就是线性不可分。

所以感知机（线性模型）不能表示 XOR。
🧩
这正是 Minsky 与 Papert 的著名论断，也引出了后来多层感知机 + 非线性激活函数（解决 XOR）的道路。
