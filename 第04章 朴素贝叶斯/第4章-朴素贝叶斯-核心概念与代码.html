00 · 换个思路

为什么会有 朴素贝叶斯？

前几章的感知机、k 近邻，都是直接学"决策边界 / 决策函数"——这叫判别方法。朴素贝叶斯走的是另一条路。

判别Discriminative
直接学 $P(Y\mid X)$ 或决策函数 $f(X)$。
如：感知机、k 近邻、决策树、SVM
生成Generative
先学"数据怎么产生" $P(X,Y)$，再用贝叶斯定理反推 $P(Y\mid X)$。
如：朴素贝叶斯、隐马尔可夫模型
1763贝叶斯定理
源自 18 世纪 Thomas Bayes 的工作（身后发表）。核心：后验 ∝ 先验 × 似然。
"朴素"在哪
假设各特征在给定类别下相互独立——这是很强的"朴素假设"，也正是它简单高效的原因。
💡
它在文本分类（如垃圾邮件识别）等任务里长期表现优秀——假设不真，但常常够用。

01 · 核心思路

生成模型：先学 联合分布，再求后验

朴素贝叶斯由训练数据学习联合概率分布 $P(X,Y)$，然后求得后验概率分布 $P(Y\mid X)$。

$P(X,Y)=P(Y)\,P(X\mid Y)$
学 $P(Y)$
类别的先验
×
学 $P(X\mid Y)$
各类别下的特征分布
→
联合分布 $P(X,Y)$
描述数据怎么产生
→
贝叶斯定理
反推 $P(Y\mid X)$
🎯
概率估计的方法可以是极大似然估计，也可以是贝叶斯估计（本节两种都会推导）。

对比记忆：判别方法学"怎么分"；生成方法学"数据长什么样"，再顺带知道"怎么分"。

第 4 章 · 朴素贝叶斯
02 · "朴素"假设

条件独立性：名字的由来

$P(X=x\mid Y=c_k)=\prod_{j=1}^{n}P\!\left(X^{(j)}=x^{(j)}\mid Y=c_k\right)$
含义
在已知类别的前提下，各个特征之间互不影响，于是联合条件概率可以拆成连乘。
为什么叫"朴素（naive）"
现实里特征往往相关（如颜色 vs 大小），这个"相互独立"的假设很不现实，故称"朴素"。
⚖️
代价换来好处：模型要估计的条件概率数量大幅减少，学习与预测大为简化，高效且易实现； 缺点是分类性能不一定很高。
第 4 章 · 朴素贝叶斯
03 · 分类决策

用贝叶斯定理 做分类

$P(Y\mid X)=\dfrac{P(X,Y)}{P(X)}=\dfrac{P(Y)\,P(X\mid Y)}{\sum_{Y}P(Y)\,P(X\mid Y)}$

把输入 $x$ 分到后验概率最大的类：

$y=\arg\max\limits_{c_k}\ P(Y=c_k)\prod_{j=1}^{n}P\!\left(X^{(j)}=x^{(j)}\mid Y=c_k\right)$
🔗
分母 $P(X)$ 与类别无关，可忽略——所以只需比较分子（先验 × 似然的连乘）。 后验概率最大，等价于 0-1 损失函数下的期望风险最小化。

这就是朴素贝叶斯做分类的全部逻辑：数一数、乘一乘、比一比大小、选最大的那个类。

04 · 三种模型

按"特征长什么样"选 概率模型

同一套贝叶斯框架，给 $P(X^{(j)}\mid Y)$ 选不同的分布假设，就得到不同版本。

高斯Gaussian
特征连续时，假设每维服从正态分布。
本节代码用的就是它 → GaussianNB
多项式Multinomial
特征是计数/频次（如文档中的词频）。
文本分类常用 → MultinomialNB
伯努利Bernoulli
特征是布尔值（某词出现/不出现）。
短文本分类 → BernoulliNB
🧩
选择原则：看特征是连续、计数还是二值，对应选高斯 / 多项式 / 伯努利。
第 4 章 · 朴素贝叶斯
04 · 高斯模型

特征连续时：高斯条件概率

条件概率密度
$P(x_i\mid y_k)=\dfrac{1}{\sqrt{2\pi\sigma_{yk}^2}}\exp\!\left(-\dfrac{(x_i-\mu_{yk})^2}{2\sigma_{yk}^2}\right)$
即：假设各特征在给定类别下服从正态分布。
两个要估计的参数
$\mu=\dfrac{1}{N}\sum_{i}X_i,\qquad \sigma^2=\dfrac{\sum_{i}(X_i-\mu)^2}{N}$
均值 $\mu$ 和方差 $\sigma^2$：按每个类别、每一维分别统计即可。
📐
预测时：对每个类别，把各维的高斯密度连乘再乘以先验，取最大者。代码里 mean / stdev / gaussian_probability 正好对应这三个公式。

05 · 核心代码 (1)

统计参数 + 训练：fit

class NaiveBayes:
    def __init__(self):
        self.model = None

    @staticmethod
    def mean(X):                       # 均值 μ
        return sum(X) / float(len(X))

    def stdev(self, X):                  # 标准差 σ
        avg = self.mean(X)
        return math.sqrt(sum([pow(x-avg, 2) for x in X]) / float(len(X)))

    def gaussian_probability(self, x, mean, stdev):   # 高斯密度函数
        exponent = math.exp(-(math.pow(x-mean, 2) / (2*math.pow(stdev, 2))))
        return (1 / (math.sqrt(2*math.pi) * stdev)) * exponent

    def summarize(self, train_data):       # 逐维统计 (μ, σ)
        return [(self.mean(i), self.stdev(i)) for i in zip(*train_data)]

    def fit(self, X, y):                  # 训练：按类别分组统计
        labels = list(set(y))
        data = {label: [] for label in labels}
        for f, label in zip(X, y):          # 把样本按类别归堆
            data[label].append(f)
        self.model = {label: self.summarize(value) for label, value in data.items()}
        return 'gaussianNB train done!'

训练阶段只做一件事：按类别统计每一维的均值和标准差——这就是"学到的模型"。

05 · 核心代码 (2)

预测：连乘求后验、取最大

    def calculate_probabilities(self, input_data):
        # model: {0.0: [(μ,σ), ...], 1.0: [(μ,σ), ...]}   input_data: 一个样本的 4 个特征
        probabilities = {}
        for label, value in self.model.items():
            probabilities[label] = 1
            for i in range(len(value)):
                mean, stdev = value[i]
                probabilities[label] *= self.gaussian_probability(   # 各维高斯密度连乘
                    input_data[i], mean, stdev)
        return probabilities

    def predict(self, X_test):
        # 选后验概率最大的类别（此处未计先验，等价于先验相同）
        label = sorted(self.calculate_probabilities(X_test).items(),
                       key=lambda x: x[-1])[-1][0]
        return label

    def score(self, X_test, y_test):      # 准确率
        right = 0
        for X, y in zip(X_test, y_test):
            if self.predict(X) == y:
                right += 1
        return right / float(len(X_test))

注意：概率是很多小数连乘，容易下溢——工程实现（如 sklearn）通常改用对数概率相加避免此问题。

06 · 习题 4.1

极大似然估计：推出公式 (4.8)(4.9)

用极大似然估计，得到先验概率与条件概率的估计公式。

公式 (4.8) · 先验概率
$P(Y=c_k)=\dfrac{\sum_{i=1}^{N}I(y_i=c_k)}{N}$
直观：某类出现的次数 ÷ 总样本数。
公式 (4.9) · 条件概率
$P(X^{(j)}=a_{jl}\mid Y=c_k)=\dfrac{\sum_{i=1}^{N}I(x_i^{(j)}=a_{jl},\ y_i=c_k)}{\sum_{i=1}^{N}I(y_i=c_k)}$
直观：在某类中，某特征取某值的次数 ÷ 该类样本数。
🪜
推导思路：把待估概率记为 $p$，写出似然函数，令其导数为 0 求极值，解出 $p=\frac{m}{N}$——本质就是"数频数、做除法"。

06 · 习题 4.2

贝叶斯估计：公式 (4.10)(4.11) 与平滑

公式 (4.10) · 条件概率
$P_{\lambda}(X^{(j)}=a_{jl}\mid Y=c_k)=\dfrac{\sum_{i=1}^{N}I(\cdot,\cdot)+\lambda}{\sum_{i=1}^{N}I(y_i=c_k)+S_j\lambda}$
公式 (4.11) · 先验概率
$P_{\lambda}(Y=c_k)=\dfrac{\sum_{i=1}^{N}I(y_i=c_k)+\lambda}{N+K\lambda}$
🧴
分子分母都加 $\lambda$：$K$ 为类别数，$S_j$ 为第 $j$ 个特征取值个数。 取 $\lambda=1$ 就是"拉普拉斯平滑"——避免某些组合没出现过导致概率为 0（一旦为 0，连乘后整个后验都归零）。

对比：极大似然估计只用"数频数"；贝叶斯估计在其上加一个先验/平滑项，更稳健。
